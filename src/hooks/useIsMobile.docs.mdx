# useIsMobile

Tracks whether the viewport is at or below a breakpoint, for components
that need a distinct mobile rendering path.

```tsx
import { useIsMobile } from '@dinofront/design_system';

function Nav() {
  const isMobile = useIsMobile();

  return isMobile ? <MobileNav /> : <DesktopNav />;
}
```

## API

```ts
function useIsMobile(breakpoint?: number): boolean; // default 768
```

Backed by `window.matchMedia('(max-width: ${breakpoint}px)')`. Returns
`false` during SSR and during the very first client render, then updates
to the real value once the effect runs after mount — so the
server-rendered markup and the client's first render always agree (no
hydration mismatch), at the cost of one extra render after mount when the
viewport actually is narrow.
